# Temp Files Cleaner

Safe and portable temporary files cleaner for Windows 10/11 written in Python.

## Features
- Dry-run mode (safe by default)
- Cleans user and system TEMP folders
- No user-specific paths
- Ignores critical system files
- GUI interface
- Logging included

## Requirements
- Windows 10 or 11
- Python 3.10+

## Usage
```bash
python cleaner.py
